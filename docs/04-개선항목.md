# 4. 개선 항목 (다음 할 일)

실사용에서 불편했던 점이 이 목록보다 우선한다.

## 1순위 — 꼭 손볼 것

- [ ] **큰 볼트 첫 실행 속도**: 볼트 파일 목록 생성(`VaultIndex` 생성자)이 UI 스레드에서 돌아 노트가 수천 개면 잠깐 멈춤 → 백그라운드로
- [ ] **한글 입력**: 영문 Windows에서 한글 입력이 불편 → 편집 모드에 두벌식 입력 내장 (HanNote 기능 통합, 한/영 전환 단축키)
- [ ] **새 버전 알림**: 실행 시 GitHub Releases를 확인해 "업데이트가 있습니다" 표시

## 2순위 — 편집 편의

- [ ] 새 노트 만들기 (Ctrl+N)
- [ ] 그림 붙여넣기 → `.obsidian/app.json`의 첨부 폴더 설정대로 저장 후 `![[그림.png]]` 삽입
- [ ] 노트 이름 바꾸기 (다른 노트의 링크도 함께 수정)

## 3순위 — 있으면 좋은 것

- [ ] 탭 끌어서 순서 바꾸기
- [ ] 나가는 링크 목록, 언링크드 멘션
- [ ] Canvas(.canvas) 보기
- [ ] Obsidian 테마(`.obsidian/themes`) 적용
- [ ] VaultIndex 링크 해석 단위 테스트 (C#)
- [ ] 코드 서명 (SmartScreen 경고 제거 — 유료 인증서 필요)

## 하지 않기로 한 것

- 옵시디언식 라이브 프리뷰 편집 (B안) — 구현 비용 대비 효용이 낮고 Obsidian과 겹침
- Dataview 등 플러그인 실행
