# 3. 설치와 사용법

## 설치

1. **[Releases](https://github.com/sungsjang/MdReader/releases/latest)** → `MdReader-Setup-x.y.z.exe` 다운로드 → 실행
   - .NET 설치 불필요, 관리자 권한 불필요
   - ".md 파일 연결" 체크 → 이후 .md 우클릭 → 연결 프로그램 → MdReader → "항상 이 앱 사용"
2. Windows "PC 보호" 경고가 뜨면 **추가 정보 → 실행** (코드 서명 인증서가 없어서 나오는 경고)

> ⚠ 저장소 첫 화면의 초록색 **Code → Download ZIP**은 소스 코드입니다. 실행 파일은 Releases에 있습니다.

설치 없이 쓰려면 `MdReader-portable-x.y.z.zip` (단, .NET 8 Desktop Runtime 필요).

## 단축키

| 단축키 | 동작 |
|---|---|
| Ctrl+P | 빠른 이동 (노트 이름·초성) |
| Ctrl+E / Ctrl+S | 편집 모드 전환 / 저장 |
| Ctrl+O | 파일 열기 |
| Ctrl+T / Ctrl+W / Ctrl+Shift+T | 새 탭 / 탭 닫기 / 닫은 탭 다시 열기 |
| Ctrl+Tab, Ctrl+1~9 | 탭 이동 |
| Ctrl+F | 문서에서 찾기 (편집 중엔 찾기/바꾸기) |
| Ctrl+\\ | 사이드바 |
| Ctrl+Shift+E / F / O / B | 파일 / 볼트 검색 / 목차 / 백링크 |
| Ctrl+D | 라이트/다크 |
| Ctrl+= / - / 0, Ctrl+휠 | 확대 / 축소 / 100% |
| Alt+← / →, 마우스 뒤로 버튼 | 뒤로 / 앞으로 |
| Ctrl+Shift+P | 인쇄 (PDF 저장 가능) |

편집 모드 서식: Ctrl+B 굵게 · Ctrl+I 기울임 · Ctrl+Shift+H 하이라이트 · Ctrl+K 링크

## 팁

- 링크를 **Ctrl+클릭** 또는 가운데 버튼 → 새 탭
- 본문 `#태그` 클릭 → 볼트 전체 태그 검색
- 검색 결과·백링크를 누르면 해당 노트가 열리고 검색어가 강조됨
- `⋯` 메뉴: 링크 미리보기 / CSS 스니펫 / 탭 복원 켜고 끄기, 탐색기·Obsidian에서 열기
- 새 창으로 따로 열기: `MdReader.exe --new-window 파일.md`
- 설정 파일: `%APPDATA%\MdReader\settings.json`

## 새 버전 배포 (개발자용)

1. `src/MdReader/MdReader.csproj`의 `<Version>` 올리기
2. `main`에 커밋 후 `git push origin main:release`
3. Actions가 빌드하고 Releases에 `vX.Y.Z`로 게시
